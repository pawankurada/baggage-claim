# Stage 3: San Francisco

Only x=3300..4950 is decorated by `src/san-francisco.js`. All layers use that clip, including the bridge parallax. Previous stage assets, controls, collision surfaces and bag positions are unchanged.

Original vector assets:
- `hill-street/victorians.svg`: three pastel hillside houses with bay windows and stepped foundations.
- `cable-car/car.svg`: one decorative classic cable car.
- `bridge/golden-gate.svg`: distant orange-red suspension bridge silhouette.

Bay, fog, shoreline, sloping road and bench are Canvas scenery inside the same Stage-3-only module. Update `sanFranciscoAssets` to replace the images without editing gameplay.
