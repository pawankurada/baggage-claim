# Stage 4: Copenhagen

`src/copenhagen.js` clips all Copenhagen scenery to x=4950..6600. It does not change collision surfaces, bag placement, controls or other stage assets.

`nyhavn/facades.svg` is an original vector illustration of narrow colorful harbor façades, steep rooflines, pale window frames, flower boxes and KAFFE signage. Update `copenhagenAssets.nyhavn` to replace it.

Bicycles with baskets, small boats, animated water reflections, low railings, café tables, a Danish flag and supported harbor lights draw inside this stage's Canvas module. No photo or generated bitmap is used. The existing fourth bag overlooks the harbor; its logic and position are unchanged.
